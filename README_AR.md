# دليل استخدام سكيل الكبسولة (hue-capsule)

السكيل بيحوّل مادة كاملة (تسجيلات المحاضرات، الشرائح، الشيتات، الامتحانات القديمة) لملفات مراجعة للامتحان. كل جملة قالها الدكتور أو
المعيد جوّه الملفات معاها اسم التسجيل والدقيقة والجملة بالنص، وكل رقم في حل مسألة بيتحسب تاني بـ SymPy. وفيه حارس (gatekeeper) بيمنع
البناء أو كلمة «خلصت» قبل ما كل الفحوصات تعدّي.

الدليل بالإنجليزي والتفاصيل التقنية: [README.md](README.md). القواعد اللي الـ AI بيمشي عليها: [SKILL.md](SKILL.md).

## 1. هتاخد إيه في الآخر

فولدر باسم `<كود المادة>_<اسم المادة>` جواه:

* `PDF/` ملفات الـ PDF: الكبسولة الماستر (عربي وإنجليزي)، القوانين، النظري، والأسئلة المحلولة (عربي وإنجليزي).
* `HTML/` نفس الملفات HTML تفتحها بدبل كليك من غير نت.
* `_evidence/` ملفات المراجعة (الأدلة، النتائج، الترتيب).

أسماء الملفات بتقول المادة والوظيفة، مثلا `ECE471_Thermal_Master_Capsule_AR.pdf`.
في الملفات العربي كل مصطلح أو قانون أو رمز بيفضل **بالإنجليزي**، والعربي للشرح بس.

## 2. اللي لازم تعرفه بصراحة

1. النسبة المئوية على كل مسألة هي **ثقة تقديرية مش احتمال مضمون**.
2. لو فيه امتحانات سابقة السكيل بيجرّب نفسه عليها ويطلّع نسبة إصابة، ولو مفيش بيكتب «غير معايَر» على كل ملف.
3. الخط اليدوي مش بيتقرا بالـ OCR، وصورة الصفحة هي المرجع.
4. التفريغ الصوتي مش مثالي، والسكيل بيرفض التفريغ الوحش. المراجعة اللي مش بسماع بشري بتتكتب كده صراحة.
5. اقرأ الملفات بسرعة قبل ما تعتمد عليها: السكيل بيتأكد من الأرقام والاقتباسات والشكل مش من جودة الشرح.

## 3. التركيب

1. نزّل الريبو وانسخ الفولدر باسم `hue-capsule` جوه فولدر الـ skills بتاع Claude (مثلا `~/.claude/skills/hue-capsule`).
2. شغّل الأمرين دول:

```bash
pip install -r requirements.txt
python scripts/setup.py
```

3. شغّل الاختبار الذاتي. لازم يخلص بـ `SELF-TEST PASSED`:

```bash
python tests/run_tests.py
```

المطلوب على جهازك: Python 3.10 أو أحدث، و `ffmpeg`، و Edge أو Chrome لتحويل HTML إلى PDF، ومتغير بيئة `GROQ_API_KEY` للتفريغ الصوتي (الاسم بس، متكتبش المفتاح في الشات).
متغير `GEMINI_API_KEY` اختياري للفحص التاني.

## 4. الاستخدام (الطريقة السريعة)

1. افتح Claude في فولدر شغل للمادة واكتب جملة واحدة: «اعمل كبسولة الميدتيرم لمادة ECE471».
2. السكيل بيدوّر لوحده على الفيديوهات والشرائح والشيتات، ومش هيسألك إلا عن اللي ملقاهوش (3 أسئلة بحد أقصى، بتجاوب بالرقم).
3. لو عندك امتحانات سابقة أو كويزات الدكتور ادّيهاله، دي أكتر حاجة بتحسّن الدقة. لو مفيش قول «مفيش».
4. لو فيديو لسه مش على جهازك: كليك يمين واختار Always keep on this device.
5. في الآخر بتاخد تقرير 5 سطور: إيه اتعمل، تفتح أنهي ملف الأول، إيه الغير مؤكد، وإيه المطلوب منك.

## 4b. لو عاوز تشغّل الخطوات بنفسك

```bash
python scripts/run_all.py <course>
python scripts/build_capsule.py <course> --pdf --lang both
python scripts/build_master.py <course> --lang both
python scripts/validate.py <course> --post-build
python scripts/package_output.py <course> --dest "<مكان الفولدر النهائي>"
```

## 5. الفحوصات (gates)

preflight، hydrate (الملفات فعلا على الجهاز)، transcripts_exist، transcript_quality، evidence (الاقتباس موجود حرفيا في التفريغ)، ledger، verify (كل رقم اتحسب تاني)، freshness (الملفات أحدث من مدخلاتها). لو فحص فشل السكيل بيقول السبب في سطر واحد.

## 6. الخصوصية

الصوت بيتبعت لمزوّد التفريغ اللي توافق عليه (Groq افتراضيا)، والفحص الاختياري بيبعت مقاطع قصيرة لـ Google. السكيل بيسألك الأول. المفاتيح من متغيرات البيئة بس، ومبتتطبعش ولا بتتخزن. السكيل مبيكتبش جوه فولدر Teams المتزامن ومبيمسحش ملفاتك القديمة.

## 7. مشاكل شائعة

* `SELF-TEST` فشل: وقّف وماتعدّلش الـ scripts، ابعت المشكلة.
* PDF مش اتبدّل: الملف القديم مفتوح في برنامج، السكيل بيحفظ الجديد باسم `_v2`.
* ملف في OneDrive «cloud only»: نزّله على الجهاز الأول.
* الـ glossary recall واطي لمحاضرات عربي بكتر: ممكن تقلله في `thresholds` بس ده بيتكتب في كل ملف.
